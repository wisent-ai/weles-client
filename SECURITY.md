# Security

Report vulnerabilities through the private GitHub Security Advisory channel for [`wisent-ai/weles-client`](https://github.com/wisent-ai/weles-client/security/advisories/new).

Do not place credentials, workflow payloads, signed receipts containing customer identifiers, private target details, or suspected executor behavior in a public issue.

Public issues may contain client API defects and documentation gaps only after all customer, target, credential, and receipt data has been removed.
